# @unbound-app/loader-ios

> [!IMPORTANT]
> This repository is archived. The Unbound loaders for iOS and Android now live in the Unbound monorepo, in [`packages/loader`](https://github.com/marioparaschiv/unbound/tree/main/packages/loader), with their full history.

## Where things are now

- **Source, issues and pull requests:** <https://github.com/marioparaschiv/unbound>
- **Releases:** loader builds are published to the monorepo as `loader-v<version>` releases. The latest one is always at [`loader-latest`](https://github.com/marioparaschiv/unbound/releases/tag/loader-latest).
- **Jailbroken (apt):** <https://builds.unbound.rip/repo>
- **Jailed (AltStore, SideStore, Feather):** <https://builds.unbound.rip/repo/app-repo.json>
- **Android (Obtainium):** track `https://github.com/marioparaschiv/unbound` with the release title filter `^loader-v`.

Existing releases and the old feed at `repo.unbound.rip` stay available here, but they no longer receive updates.
